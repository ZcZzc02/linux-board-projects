三、RS485 透传指令（rs485_raw）—— 最通用
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

直接把任意字节发到 RS485 总线，F767 不做任何解析，纯透传。
适合所有 Modbus 功能码及自定义协议。

参数：
  "hex"  : 十六进制字节串（无空格或有空格均可），不含 CRC
           UI 勾选"自动追加 CRC16/Modbus"后 JS 会自动计算并追加

LoRa 帧格式：[0x01][0x41][inner_len][inner bytes...][CRC_H][CRC_L]

────────────────────────────────────────────────────────────────────────────────
【Modbus FC01】读线圈（Read Coils）
────────────────────────────────────────────────────────────────────────────────
帧结构：[从机地址][01][起始地址H][起始地址L][数量H][数量L][CRC]

示例：读从机1，从第0个线圈开始，读8个线圈
  HEX字节（不含CRC）：01 01 00 00 00 08
  UI填写：  010100000008
  勾选自动CRC → 实际发出：01 01 00 00 00 08 3D CC

响应示例：01 01 01 AB xx xx
  [01]=从机地址  [01]=FC  [01]=1字节数据  [AB]=8个线圈状态（bit0~bit7）

────────────────────────────────────────────────────────────────────────────────
【Modbus FC02】读离散输入（Read Discrete Inputs）
────────────────────────────────────────────────────────────────────────────────
帧结构：[从机地址][02][起始地址H][起始地址L][数量H][数量L][CRC]

示例：读从机1，从第0个离散输入开始，读8个
  UI填写：  010200000008
  勾选自动CRC → 实际发出：01 02 00 00 00 08 79 CC

────────────────────────────────────────────────────────────────────────────────
【Modbus FC03】读保持寄存器（Read Holding Registers）★ 最常用
────────────────────────────────────────────────────────────────────────────────
帧结构：[从机地址][03][起始地址H][起始地址L][数量H][数量L][CRC]

示例1：读从机1，从第0号寄存器开始，读4个（8字节数据）
  UI填写：  010300000004
  勾选自动CRC → 实际发出：01 03 00 00 00 04 44 09
  F767打印：RS485 passthrough len=8  / RS485 resp rxlen=13

示例2：读从机2，从第100号寄存器（0x0064）开始，读1个
  UI填写：  020300640001
  勾选自动CRC → 实际发出：02 03 00 64 00 01 85 E2

示例3：读从机1，从第0x0400号寄存器开始，读1个（读F767从机地址）
  UI填写：  010304000001
  勾选自动CRC → 实际发出：01 03 04 00 00 01 ...

响应格式（读4个寄存器为例，共13字节）：
  01 03 08 [R0H][R0L] [R1H][R1L] [R2H][R2L] [R3H][R3L] [CRC_L][CRC_H]
  每个寄存器为16位大端序

────────────────────────────────────────────────────────────────────────────────
【Modbus FC04】读输入寄存器（Read Input Registers）
────────────────────────────────────────────────────────────────────────────────
帧结构：[从机地址][04][起始地址H][起始地址L][数量H][数量L][CRC]

示例：读从机1，第0号输入寄存器，读2个
  UI填写：  010400000002
  勾选自动CRC → 实际发出：01 04 00 00 00 02 71 CB

────────────────────────────────────────────────────────────────────────────────
【Modbus FC05】写单个线圈（Write Single Coil）
────────────────────────────────────────────────────────────────────────────────
帧结构：[从机地址][05][地址H][地址L][值H][值L][CRC]
  值：0xFF00 = 线圈ON，0x0000 = 线圈OFF

示例1：将从机1第0号线圈置ON
  UI填写：  0105000000FF00    （注意不勾CRC也可手动填完整帧）
  勾选自动CRC → 完整帧：01 05 00 00 FF 00 8C 3A

示例2：将从机1第0号线圈置OFF
  UI填写：  010500000000
  勾选自动CRC → 完整帧：01 05 00 00 00 00 CD CA

────────────────────────────────────────────────────────────────────────────────
【Modbus FC06】写单个保持寄存器（Write Single Register）★ 常用
────────────────────────────────────────────────────────────────────────────────
帧结构：[从机地址][06][地址H][地址L][值H][值L][CRC]

示例1：向从机1第0号寄存器写入值 0x1234
  UI填写：  010600001234
  勾选自动CRC → 实际发出：01 06 00 00 12 34 82 43

示例2：向从机1第3号寄存器写入值 100（0x0064）
  UI填写：  010600030064
  勾选自动CRC → 实际发出：01 06 00 03 00 64 39 D0

示例3：向F767节点的RS485从机地址寄存器(0x0400)写入新地址2
  UI填写：  010604000002
  勾选自动CRC → 完整帧：01 06 04 00 00 02 ...

────────────────────────────────────────────────────────────────────────────────
【Modbus FC10 (0x10)】写多个保持寄存器（Write Multiple Registers）
────────────────────────────────────────────────────────────────────────────────
帧结构：[从机地址][10][起始地址H][起始地址L][数量H][数量L][字节数][数据...][CRC]

示例：向从机1从第0号寄存器开始写2个寄存器（值：0x0001, 0x0002）
  字节数 = 数量 × 2 = 04
  UI填写：  0110000000020400010002
  勾选自动CRC → 发出：01 10 00 00 00 02 04 00 01 00 02 xx xx
  响应：      01 10 00 00 00 02 [CRC]（回显地址和数量）

────────────────────────────────────────────────────────────────────────────────
【自定义/私有协议】
────────────────────────────────────────────────────────────────────────────────
可以发任意字节，例如某私有协议帧 AA BB CC DD：
  UI填写：  AABBCCDD
  不勾CRC（协议自带校验）
  F767 原样透传到 RS485 总线，等待响应

四、RS485 读写指令（rs485_read / rs485_write）—— 旧机制
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

注意：这两个指令走 LoRa FC03/FC06，网关构造帧后通过 LoRa 发给 F767。
F767 的 Modbus_Process 中 case 0x06 仅操作 F767 自身的 ADDRES_REGISTER(0x0400)
（设置 F767 作为 Modbus 从机时的地址），不会透传到 RS485 总线下游从机。
如需操作下游从机，请使用 rs485_raw。

【rs485_read】读 F767 自身寄存器
  参数：{ "slave": 从机地址, "reg": 寄存器地址 }
  示例：{ "node_id":"1", "cmd":"rs485_read", "params":{"slave":1,"reg":0} }

【rs485_write】写 F767 自身寄存器（仅 0x0400 有效：设置 RS485 从机地址）
  参数：{ "slave": 从机地址, "reg": 寄存器地址, "data": "XXYY" }
  示例：{ "node_id":"1", "cmd":"rs485_write", "params":{"slave":1,"reg":1024,"data":"0002"} }
  → 将 F767 的 RS485 从机地址寄存器设为 2

五、其他系统指令

【enable_discharge / disable_discharge】使能/禁止放电
  { "node_id":"1", "cmd":"enable_discharge", "params":{} }

【set_charge_power / set_discharge_power】设置充/放电功率
  { "node_id":"1", "cmd":"set_charge_power", "params":{"power_w":500} }

六、CRC16/Modbus 快速计算说明
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

上位机 UI 已内置 JS 实现，勾选"自动追加 CRC16/Modbus"即可。
手动计算规则（如需在其他工具中使用）：
  - 多项式：0xA001（反转多项式，等效 0x8005）
  - 初始值：0xFFFF
  - 字节序：低字节在前（小端），即先发 CRC & 0xFF，再发 CRC >> 8
  - 在线工具：https://crccalc.com  选择 CRC-16/MODBUS

常用帧 CRC 速查：
  01 03 00 00 00 04  →  44 09
  01 03 00 00 00 01  →  0A 84
  01 06 00 00 00 01  →  48 0A
  01 06 04 00 00 02  →  08 79

七、F767 串口打印含义速查
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

RS485 passthrough len=N   → F767 收到 FC41 指令，内层数据 N 字节，将发往 RS485
RS485 resp rxlen=M        → RS485 从机响应了 M 字节（成功）
RS485 passthrough: no resp→ RS485 从机无响应（超时，检查接线/波特率/地址）
[485] Volt=x Curr=x ...   → 周期性主动轮询从机成功，显示寄存器值
[485] timeout rxlen=0     → 周期性轮询超时（正常轮询无从机时也会出现）
[485] CRC error           → 收到响应但 CRC 校验失败（干扰/波特率不匹配）
[485] frame error         → 收到响应但地址/功能码不符
